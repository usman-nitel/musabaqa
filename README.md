# Musabaqa

Musabaqa is an information site for Qur'an recitation competitions in Northern Nigeria. It is currently a frontend built with mock data; all names, scores, dates, and contacts are illustrative.

## Tech stack

Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## Run locally

```bash
npm install
npm run dev
```

## Participant data

No real participant data belongs in this repository. Keep participant names, scores, dates, and contacts illustrative unless appropriate consent and approval have been obtained.
